# Calibration reference image slots

These optional PNG files appear in the **Reference example** panel. They are
visual instructions only and are never read by meter detection.

| Calibration task | Filename |
|---|---|
| Complete timing meter | `complete_meter.png` |
| Green target | `green_target.png` |
| Black marker | `black_marker.png` |
| Track / gradient | `track_gradient.png` |

Replace or add a file while the calibrator is open, then reselect its task to
refresh the preview. Use tightly cropped, sanitized images without usernames,
chat, player lists, or other personal information.
